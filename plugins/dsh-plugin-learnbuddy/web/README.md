# LearnBuddy Web · 初始交互 Demo

这是一版用于产品与 UI 讨论的前端演示，按黄山在 2026-09-10 确认的师生、课程与作业关系实现。人物、课程、课件与报告均为虚构示例。**整理、生成和评阅采用本地模拟；学习对话已内嵌本地 DSH，模型尚未配置。**

后续已补 [DSH 原生界面插件](dsh-ui/README.md)：实际加载于本地 DSH，在材料和反馈页内嵌原生会话，带入文字引用并保留草稿，无需跳转独立页面。**这不代表模型、正式业务接口或师生权限已接通。**

## 启动与打包

已在 Node.js 20.20.2 验证。需要 Node.js 20.19+ 或符合 Vite 8 要求的更新版本。

```sh
npm ci
npm run dev
```

打开 `http://127.0.0.1:5178/learnbuddy/`。默认只监听本机。若本机 npm 默认缓存不可写，可附加 `--cache /private/tmp/learnbuddy-npm-cache`，不需要修改系统权限。

```sh
npm run test
npm run build
npm run preview
```

构建产物位于 `web/dist/`，资源前缀为 `/learnbuddy/`，页面切换使用 hash。保持与嘉俊约定的插件目录一致；新增 UI 插件已验证本地 DSH 静态挂载，团队服务器仍需单独集成，当前没有上线。

开发环境使用文件轮询，便于本地工具改动后更新。状态上下文单独放置，避免热更新期间实例不一致。页面出错时提供重新加载入口。

## 推荐体验路径

1. 学生林一：资料库 → TCP 课件 → 本页学习助手 → 引用示意图说明 → 加入当前问题。输入和草稿可操作，发送模型问题及教师答疑卡检索仍待接入。
2. 学生林一：作业与报告 → TCP 实验 → 使用演示报告提交。
3. 教师陈知行：作业与报告 → 进入评阅 → 批量评阅 → 单份报告逐项复核 → 调整分数 → 确认反馈。
4. 切回林一：查看自己的已确认结果。教师尚未确认时，学生只能看到等待状态。
5. 教师陈知行：教学反馈 → 查看已确认报告统计 → 生成示例教学建议。
6. 教师创建新作业：生成要求和标准、编辑草稿、关联资料、确认发布；学生按课程关系接收作业。

## 实现范围与边界

- 八类页面：统一登录、资料库、材料工作台、作业与报告、实验设置、评阅管理、报告详情、教学反馈。
- 上传校验覆盖 PDF / PPT / PPTX / DOCX / PNG / JPG / JPEG，单文件最大 20 MB。元数据放在 localStorage，原始文件放在 IndexedDB。真实文件不会产生伪造解析或评分结果。
- 图片与 PDF 使用原文件预览；Office 文件可保存/下载，在线转换等待后端。样例课件为原生 HTML 内容与 SVG 图示，不是伪装成真实文件的 PDF；样例课件下载为明确标识的 HTML。
- 教师可编辑知识点、生成/编辑/确认答疑卡、准备教学提纲、生成/编辑/确认实验标准。所有生成均明确标识为模拟。
- 报告逐项评分可人工编辑，程序验证分值范围和求和，确认记录保留。自定义评分项不在样例覆盖范围时留待人工填写，不生成虚构依据。
- 批量任务在同一浏览器页面内切换路由时继续；刷新中断会标记需重试，不宣称具备服务器后台任务能力。
- 教学统计只使用本课程已确认报告，按名称和判据合并评分项，不读学生聊天。未确认分数不对学生显示。
- 切换账号仍在同一浏览器存储空间内。这是前端权限行为演示，不是服务端安全边界；正式接入必须由后端实施身份、课程、文件和结果权限校验。
- 通过「演示说明 → 重置演示数据」恢复样例并清理本浏览器上传文件；只在需要时使用。

## 代码地图

| 文件 | 职责 |
| --- | --- |
| src/types.ts / seed.ts | 前端实体关系、虚构课程与示例内容 |
| src/domain.ts | 账号、课程与资料可见范围；评分校验、确认、统计 |
| src/store-context.ts / context.tsx | 稳定状态上下文、持久化更新、页面路由、模拟异步任务 |
| src/storage.ts | 浏览器记录与原始文件保存 |
| src/pages/Library.tsx | 课程资料列表、筛选与上传 |
| src/pages/Material.tsx | 文档、知识点、备课内容与助手位置 |
| src/components/DshAssistant.tsx | 材料/反馈页共用的内嵌 DSH 会话与引用、连接/重试 |
| src/pages/Assignments.tsx | 作业、评分依据、批量评阅、单份复核、教学反馈 |
| src/ui.tsx / styles.css | 共用控件、原创图示与响应式样式 |
| src/domain.test.ts | 课程隔离、隐私边界、评分与统计、文件校验测试 |
| src/dsh.ts / dsh.test.ts / dsh-bridge.test.ts | 当前资料引用、iframe 确认机制；文件、长度、来源和上下文边界 |
| dsh-ui/ | DSH 主题与插槽插件、静态挂载、本地预览启动方式 |

本轮没有修改嘉俊维护的 `../src/` 与 `../server.js`。新增静态挂载位于独立 `dsh-ui/host.js`，通过 DSH 官方 WebServer 接口承载页面。后续再与嘉俊确定身份与课程到 DSH 会话的映射、业务 API、解析、存储和部署；不把现有 Mock API 当成完整产品接口。
