## 六、方法论沉淀

**如何快速识别「表演型实现」：**

1. **搜关键词**：`模拟` / `mock` / `占位` / `假` / `待接入` / `示例` / `placeholder`
2. **看注释自述**：如果注释里有「模拟」「用于演示」但**界面没有对应标记**，就是问题
3. **判别标准（关键）**：
   - ✅ **诚实**：数据是假的，但**用户能看出来它是假的**（有标记/文案/降级提示）
   - 🔴 **欺骗**：数据是假的，且**用户看不出来**（伪装成真实结果）
4. **反例（今天修掉的两个）**：
   - `material-context.js` 合成正文 → 界面显示成「提取正文」，**无任何标记** 🔴
   - `Library.tsx` 定时器进度 → 显示成真实上传进度，**无任何标记** 🔴
5. **正例**：`llm.js` 的 `mock: true` → 前端显示「降级回答 · 未调用模型」 🟢

**核心区别不是「用不用假数据」，而是「用户能不能分辨」。**
