# 课程层级与统一助手改版 · 2026-09-12

此记录接续同日的师生工作台改版，描述当前本地界面。这里的 UI 与导航说明优先于此前记录。当前预览为 `http://127.0.0.1:5178/learnbuddy/`，仍使用本机独立教学样例库，未部署公网。

## 六项反馈对应的变更

| 反馈 | 当前实现 |
| --- | --- |
| 课件答疑与 DSH 对话重复 | 资料页只有一个原生 DSH 助手：学生显示“学习助手”，教师显示“备课助手”。移除双助手切换，材料、选中原文与教师已确认答疑卡可进入同一输入框。 |
| Agent 与语音 UI 粗糙 | 重做助手标题、欢迎区、引用与输入区。语音通过 DSH 公开的 `conversation.input.right` 插槽进入原生工具行，录音时展示波形与计时，停止后展示转写状态。 |
| 三个目录点击无有效跳转 | 学习/教学空间 → 工作台；课程学习/任教课程 → 课程总览；课程名称 → 对应课程页。资料页返回按钮也回到所属课程。 |
| 全部资料/老师共享/我的笔记含义不清 | 默认列表只显示本课程公开课件。个人参考资料为次级可折叠区域，并说明课外文档、阅读笔记的使用情景与可见范围。教师另有“我的备课文件”，学生没有“发布资料”入口。 |
| 课程藏在原始下拉栏 | 侧栏直接列出课程，课程总览以独立卡片呈现，课程页包含资料与本课程作业入口。作业页的课程筛选只承担筛选职责。 |
| 使用现代组件和动效 | 接入 Radix Themes 3.3 与 Motion 13.2。实际使用 Dialog、Select、Popover、Tooltip、TextField、Button、IconButton、SegmentedControl；导航标记、页面和折叠区域使用 Motion，遵循减少动态效果偏好。 |

组件资料：[Radix Themes](https://www.radix-ui.com/themes/docs/overview/getting-started)、[Motion for React](https://motion.dev/docs/react)。组件库是实现基础；视觉结果以浏览器实测和用户审阅为准。

## 信息层级与状态

- `#home`：个人工作台。继续阅读、学生未交作业或教师待处理提交，以及课程入口。
- `#courses`：课程总览。旧的 `#library` 仍可进入课程总览。
- `#course/:id`：单门课程资料与作业入口。
- `#assignments/:courseId`：按课程筛选的作业；`#assignments` 是全部课程。
- `#insights/:courseId`：教师课程学情；`#insights` 是课程学情总览。
- 材料、作业和反馈详情从实际记录确定课程。浏览器后退会恢复 URL 中的课程范围，避免只改标题、未改内容。

手机阅读页使用“阅读资料 / 学习助手”切换；离开助手视图时卸载内嵌会话界面，听写控制器按已有生命周期取消并释放资源。桌面保持正文与助手并排。

## 引用与语音

当前材料以待附引用呈现；点击“附到问题”后，原文及已确认答疑卡进入可编辑草稿。不会自动发送消息，也不会把未确认草稿当成教师参考。引用已加入后防止重复添加；若用户清空或移除引用文字，按钮重新可用。

本次复用已配置的本机语音接口，没有修改模型、密钥或语音服务部署。语音只填入草稿，录音最长 60 秒。真实语音服务的前次样本证据与密钥配置见 [LLM 与免费语音配置](LLM_AND_VOICE_SETUP.md)。

## 本轮验证

- 前端 40 项检查通过，包括四项导航测试、新增的教师答疑卡引用范围测试，以及既有接口、DSH 连接、资料权限与语音生命周期测试。
- TypeScript/Vite 生产构建、DSH 插件构建通过。React、组件库和 Motion 分包，最大 JS 文件约 219 KB，构建无超大 JS 分块警告。
- 桌面浏览器实际点击三个目录层级、课程卡片、课程作业、全部课程筛选及浏览器后退；课程与内容对应。
- 实际检查教师工作台、学生工作台、教师成绩表与课程学情详情。成绩表保留学生、提交状态、建议分、正式分数和操作。
- 440px 内置浏览器实际检查登录、侧栏课程、课程资料、完整目录、阅读视图、助手视图；麦克风和发送按钮在助手首屏可见。
- 统一助手实际接收服务器正文与教师确认答疑卡，点击引用后进入唯一输入框；验收草稿已清空，没有发送模型消息。
- 搜索弹窗自动聚焦输入框，一次 Escape 关闭并恢复触发按钮焦点；桌面控制台未发现错误或警告。

真实模型回答仍缺 API Key，因此本轮没有验证 LLM 实答。没有录制用户环境声音，现场麦克风与转写准确率仍需口述验收。此前记录中的新报告接收门禁、正式认证、教师内容发布接口及评分依据问题仍需相应后端工作；本轮 UI 改版不代表这些能力已经完成。
