## 1. 代码与启动

前端位于原指南约定的 `plugins/dsh-plugin-learnbuddy/web/`。本轮没有修改业务插件 `src/`、`server.js`、模型服务或已有后端接口。前端不会调用现有 Mock API，当前业务数据和文件保存在浏览器。

在新的本地检出中运行；已有该分支时直接切换，不在有未提交改动的运行目录切分支：

```sh
git fetch origin
git switch --track origin/codex/learnbuddy-frontend-demo
cd plugins/dsh-plugin-learnbuddy/web
npm ci
npm run build
npm test
```

完整内嵌体验需要 **Node.js 22.19+ 或 24+**，DSH 实测版本为 **`@deepseek-ai/dsh@0.1.5-rc.1`**：

```sh
npm run setup:dsh
npm run dev:dsh
```

首次打开命令输出的 DSH 鉴权链接，登录后进入 `http://127.0.0.1:3089/learnbuddy/`；课件直达 `http://127.0.0.1:3089/learnbuddy/#material/mat-tcp`。鉴权参数不提交仓库或写入分享链接。

- 单独开发网页：`npm run dev`，入口 `http://127.0.0.1:5178/learnbuddy/`；内嵌对话仍需 DSH 进程。
- 网页产物：`web/dist/`；DSH 浏览器插件产物：`web/dsh-ui/dist/client.js`，可用 `npm run build:dsh` 单独构建。
- `.dsh-preview/` 是隔离的 DSH 依赖、配置、Session 和预览工作区，已忽略，不提交或打入发布包。启动脚本不使用个人 `~/.dsh`。
- 预览只监听回环地址。服务器可运行同样的预览，经 SSH 转发以本机地址访问；不能把演示身份当作正式学生登录。
- 完整说明：[前端 README](../plugins/dsh-plugin-learnbuddy/web/README.md)、[DSH 集成 README](../plugins/dsh-plugin-learnbuddy/web/dsh-ui/README.md)。

## 2. 已确认的产品关系

- 单一登录入口，账号决定师生身份；一位教师可有多门课，每门课一位教师，课程与学生多对多。首版不做班级、选课、学期管理。
- 所有材料绑定课程。教师可共享本课程材料或保留私人备课材料；学生个人上传只对自己可见。教师不读取学生私人聊天。
- 实验作为作业，报告关联作业和提交学生。教师只管理自己的课程，学生只能看自己的报告与教师已确认反馈。
- 解析、生成知识点/答疑卡/评分表、批量评阅及统计建议在相应页面通过按钮或后台处理完成，不要求进入对话。
- DSH 对话用于材料问答、看图解释、连续追问、开放式备课及可选反馈解读；不会通过聊天自动修改分数。
- 教学反馈仅统计本课程提交的作业与已确认评阅，不把私人聊天纳入分析。
- Web 首版；PDF、PPT/PPTX、DOCX、PNG/JPG，单文件 20 MB，不设固定页数上限。自测题后置，学生提交前预评分未定。

## 3. 页面实现与后台接点

「待接」是本轮前端所需能力，不表示现有服务器已支持，也不冻结具体 URL 或数据库方案。

| 页面 | 当前可体验 | 后台待接 |
| --- | --- | --- |
| 统一登录 | 虚构账号进入、退出、切换，按身份显示操作 | 真实登录、会话校验、账号与课程关系 |
| 资料库 | 查找、课程筛选、共享/私人范围，文件保存与下载 | 文件存储、权限、解析状态及失败重试 |
| 材料工作台 | 原文与知识点定位，教师编辑知识点/答疑卡，内嵌助手 | 图文解析与来源、真实生成、教师确认内容、Agent 读取获准材料 |
| 作业与报告 | 教师创建作业，学生提交，自己的状态与历史 | 作业/提交持久化、课程范围、重复提交与版本 |
| 实验设置 | 要求和评分项生成演示、编辑、确认发布 | 读取已有要求/评分表，真实生成，保存依据版本 |
| 评阅管理 | 导入报告、学生匹配、单份/批量任务与失败状态 | 后台持续任务、逐份重试、按同一依据评阅 |
| 报告详情 | 原文/证据、逐项改分、校验求和、确认记录、学生反馈解读 | 真实证据与页码、原子确认、权限、评阅版本 |
| 教学反馈 | 据当前已确认记录计算统计、示例教学建议 | 查询真实课程数据并据此生成有来源的建议 |

上传的真实文件不会被编造成已解析内容。图片/PDF 可预览原文件；Office 当前可保存和下载，转换待接。样例课件是标明示例的 HTML 与 SVG，样例报告评分来自固定演示数据。

## 4. 数据与状态交接

以 [`src/types.ts`](../plugins/dsh-plugin-learnbuddy/web/src/types.ts) 为前端实体参考，以 [`src/domain.ts`](../plugins/dsh-plugin-learnbuddy/web/src/domain.ts) 为界面侧校验参考。它们不是服务端授权实现。

| 实体/状态 | 需要保留的关联或行为 |
| --- | --- |
| User / Course / Enrollment | 身份、课程教师、课程学生范围 |
| Material | `courseId`、`ownerId`、`visibility`；文件与解析结果、知识点来源、答疑卡确认状态 |
| Assignment / Rubric | 作业关联课程及材料；评分项 ID、判据、上限、确认与发布状态 |
| Submission | `assignmentId`、`studentId`；文件、建议分、评语、证据位置、教师确认历史 |
| 评阅状态 | `submitted → grading → review → published`；失败为 `failed`，可单份重试 |
| Grade | 分数可为空，必须在评分项范围内；程序求和，缺证据或未评分不能编造成完成 |
| ReviewVersion | 教师确认时保存分数、评语和摘要快照；聊天解读不更新这些字段 |

当前业务记录在 localStorage，文件在 IndexedDB，登录身份在 sessionStorage。跨设备不共享。模拟任务切页可继续，刷新后中断任务标为失败；正式版本须由服务器保存状态并继续执行。接入时统一读取/更新与错误处理，替换 `context.tsx`、`storage.ts` 的本地实现，不在组件内各接一套数据。

已有报告后界面锁定评分依据编辑；后端还需保存报告对应的依据版本。学生查询待确认报告时，应由服务端过滤建议分，不能返回完整结果后仅在前端隐藏。

## 5. DSH 接入要点

[`DshAssistant.tsx`](../plugins/dsh-plugin-learnbuddy/web/src/components/DshAssistant.tsx) 供材料和反馈页共用，iframe 指向同源 `/?learnbuddy=embedded`。`dsh-ui/host.js` 用官方 WebServer 接口挂载 `/learnbuddy/`，`client.cjs` 用 Client Module / Slot 改主题、欢迎行与对话外壳，保留原生编辑器与会话能力。

桥接流程：父页面发 `learnbuddy:init` → 子页面关联预览 Session 并回 `learnbuddy:ready` → 父页面发 `learnbuddy:context` → 子页面回 `learnbuddy:received`。校验精确 origin、来源窗口、请求 ID 与 `用户ID:材料或报告ID`，拒绝超长数据及不匹配上下文；超时提供原位重试。

引用先显示资料卡，用户点击才追加到原生输入框，不自动发送或覆盖已有草稿。目前只带入真实存在的文字、样例正文或图片说明，**原始图片、PDF、Office 文件尚未传入 Agent**。正式版需提供获准的文件读取和图像内容，不能只传文件名后声称模型已看图。

Session 对应关系存在浏览器 `learnbuddy.dsh.session.v1:<contextKey>`，只解决预览连续性。自动创建仅在宿主注入预览工作区且浏览器访问本机地址时启用。正式域名会提示缺少课程学习会话映射；应由后端依据已认证用户返回获准的 Workspace/Session，不能删除限制后让学生共用开发者工作区。

DSH 根路径仍是维护入口，含通用工作区和工具能力。现有 `3088` 网关转发非业务请求，集成时须验证 HTTP、WebSocket 升级与鉴权；网关代码未显式实现 WebSocket upgrade，本轮没有替换它。正式师生入口必须与开发者管理权限分开。

主题和欢迎行使用公开 Slot；原生标题组隐藏、输入空白提示局部适配依赖 `0.1.5-rc.1` 结构。升级后复核这些位置、输入和引用功能，不直接改安装包。

## 6. 验收路线与限制

演示账号密码均为 `123`。`student.lin` 是林一，`teacher.chen` 是计算机网络/操作系统教师陈知行，`teacher.lin` 是数据库教师林悦；另有 `student.zhou`、`student.xu`。登录页可直接选账号，旧 `user / 123` 映射林一，仅为演示数据。

1. 林一进入 TCP 课件：助手在本页且欢迎文案为学习场景；输入草稿后引用图说明，追加后原草稿还在。
2. 切知识速览、收起再打开助手、切课件再回来：当前材料草稿恢复，其他材料使用自己的会话。
3. 林一提交样例报告，陈知行批量评阅、改分并确认，再切林一：未确认分数不可见，确认后可看但不可编辑。
4. 已确认报告点击「聊聊反馈」：本页原生对话与摘要，不跳新页面，不自动改分。
5. 切林悦或另一学生，核对课程和私人材料范围；真实上传不产生虚构解析或评分。
6. 390px 手机打开材料：无整页水平溢出，初始化保持原文位置；主动点图引用才滚到助手。
