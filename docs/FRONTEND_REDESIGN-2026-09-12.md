> 同日后续改版已更新课程入口、资料分类和统一助手；当前界面以 [最新 UI 验收记录](UI_HIERARCHY_AND_ASSISTANT-2026-09-12.md) 为准。下文保留此前业务接入与验证记录。

当前版本可在本机验收，尚未更新公网。课程与人物为独立教学样例，读写使用本机 SQLite。此记录接续同日的首次接口接入记录；发生冲突时以本记录为准。

## 页面与角色

| 页面 | 教师 | 学生 |
| --- | --- | --- |
| 主导航 | 教学资料、作业管理、学情分析 | 课程学习、我的作业 |
| 课程切换 | 任教课程的单一下拉框 | 已选课程的单一下拉框 |
| 资料列表 | 已共享课件、个人备课；上传教学资料 | 老师共享、我的笔记；上传强制私有 |
| 资料阅读 | 提取正文、知识点、备课笔记、答疑卡；备课提示 | 提取正文、知识点；阅读提示 |
| 作业列表 | 发布状态、提交/应交、待复核、已发布反馈、设置与评阅 | 自己的提交状态、正式成绩、任务与反馈 |
| 学生成绩总表 | 按学生/账号/作业搜索；按状态筛选与分数排序；CSV 导出 | 不显示 |
| 作业设置 | 基本信息、任务要求、关联材料、评分标准表；保存草稿、确认发布 | 只读任务要求与评分标准 |
| 评分与反馈 | 全班名单，最新提交，核定分数、评语和发布 | 只展示本人已发布评分与反馈 |

“全部课程”是同一个课程选择器中的汇总选项，移除独立课程卡片与重复课程导航。主体使用紧凑工具栏、表单和表格，减少装饰卡片、重复标题与空白。手机导航收起，宽表局部横向滚动。

DSH 内嵌区域移除原生侧栏、会话大标题和重复输入区；材料引用折叠，直接使用原生输入框。保留模型选择、附件、引用与语音输入。引用和听写只进入草稿，由用户决定发送。

## 本轮接通的数据操作

- `GET /api/learnbuddy/workspace?userId=…`：按账号读取课程、作业、提交与教师名单；学生响应再次移除历史中的未发布成绩及内部失败信息。
- `POST /api/learnbuddy/assignments`、`PUT /api/learnbuddy/assignments/:id`：教师创建/修改/发布作业，校验课程、评分项、关联共享资料和发布确认；已有提交的作业锁定评分标准与发布状态。
- 登录响应携带实际课程；切换账号时清除上一账号数据并取消未完成请求。已保存提交的评分可直接读取，评阅不依赖前端固定提交 ID。
- 默认问答不再把无 Key 的固定 Mock 内容标成模型回答；未获得有效模型输出时显示服务状态，不返回无关的固定 TCP 建议，也不把全局 Mock 卡片冒充任课教师答疑。
- 本机 Whisper 语音服务接入普通表单和 DSH，配置与使用见 [LLM 与免费语音配置](LLM_AND_VOICE_SETUP.md)。

## 验证

- 前端 TypeScript/Vite 构建、DSH UI 构建通过；前端 35 项、后端 191 项测试通过。
- 桌面浏览器实际检查教师作业表、课程过滤、新建表单、学生资料与个人作业、DSH 内嵌；440px 内置浏览器检查成绩表，宽表在自身区域滚动。
- 教师界面创建草稿并得到数据库生成的 ID；切换学生后草稿不可见。验收产生的草稿已清理。
- DSH 登录后完成引用握手，材料正文加入原生输入框，没有自动发送。修改代理后本机同源与连接检查通过。
- 本机语音接口实际转写公开中文样本：5.616 秒音频返回“开放时间早上9点至下午5点”。使用 [SenseVoice 官方公开样本](https://huggingface.co/FunAudioLLM/SenseVoiceSmall/blob/main/example/zh.mp3)，没有录制用户环境声音。语音生命周期测试覆盖停录释放、页面关闭取消、录音错误不上传及 60 秒限时。
- 当前没有 API Key，因此没有验证本轮真实 LLM 回答或模型评分。现场麦克风、中文专业术语识别仍需人工验收。

## 仍需后端补齐

新报告接收、交错作业/缺任务点检查、退回补充及异常回流尚未接入；提交按钮明确显示待接入。知识点、答疑卡与备课内容的完整保存发布仍有缺口，备课草稿目前只保留在本次登录。

正式密码、令牌和文件授权仍未完善；按账号过滤的数据测试不能当作完整安全认证。AutoGrader 的真实报告读取、多模态证据、评分来源标记及规则建议正确性仍须专项验收。当前不是完整教学闭环或赛题能力全部完成的证明。

本轮仅修改本地分支与本机预览。没有写入公网教学库、发布真实学生成绩或部署公网服务。
