# 前端接口接入与交互修正 2026年9月12日

> 后续同日已完成师生工作台与 DSH 改版，并补充工作台读取、作业表单和本机语音服务。本文件保留首次接入时的历史证据；当前状态以 [改版记录](FRONTEND_REDESIGN-2026-09-12.md) 为准。

本轮已形成可本地验收的前端版本：默认连接服务器课件、原文、答疑和教学统计，并接入已有评阅接口。尚未部署到公网，不代表完整教学闭环或两个赛题已经完成。

依据：先阅读嘉俊的 [对接指南](https://github.com/toustifer/learnbuddy/blob/ff3ba14/docs/FRONTEND_INTEGRATION_GUIDE.md)，再核对 [接口参考](https://github.com/toustifer/learnbuddy/blob/ff3ba14/docs/API.md)；仓库主分支快照为 `ff3ba14`。Word 中的截图与评论作为建议材料，以下实现选择由本轮结合已确认需求作出。

## 本轮改动

- 导航明确为“按课程筛选当前模块”；切换课程保留资料、作业或反馈模块。面包屑可返回空间、模块与课程。
- 课程卡片只负责进入课程，进入后不再通过重复点击大卡片退出。提供明确返回入口。
- “继续上次阅读”仅显示当前账号实际打开过、仍有权查看的资料。共享和私有筛选增加说明，搜索框与清空按钮补足边界。
- 字号显示实际数值；移除手机端把正文锁定为 14px 的旧样式。原件预览与提取正文分开，字号只作用于可调的正文。
- 登录使用服务返回的身份。所有资料列表与上下文请求均携带 `userId`；切换账号清空本次资料和评阅缓存，并取消旧资料请求。
- 资料上传使用 multipart，学生上传强制私有；成功上传与成功解析分开呈现。失败展示具体原因，旧记录只有 pending 时显示“未完成解析”，不展示持续加载动画。
- 默认课件答疑调用 `/qa/ask`。已核对的教师答疑卡、模型响应、降级响应分别标注；课件未解析时不允许假定已读取正文。网络错误保留问题草稿。
- 保留内嵌 DSH；开发环境同源代理到现有网关。DSH 引用优先使用实际获取的正文，禁止用同名本地课件替代服务器材料；引用只进入可编辑草稿，不自动发送。
- 单份评阅、失败重试、批量评阅与教师发布已封装并提供入口。请求启用 `strictLLM`；评分标准取自服务器作业统计中的 rubric。展示返回的页码和原文证据，不使用前端造分。当前评分响应缺少明确来源字段，因此标为“服务器评阅结果”。
- 教师核定分数必须完整、唯一且不超出服务器单项满分；发布使用 `strictRange`。本次结果在同一次登录内跨页面保留，退出或刷新后清空。发布和批量操作需要界面内确认。
- 教学反馈读取服务器课程统计；已发布数量为零时不展示 0 分成绩、分布或“表现优异”等无依据建议。规则建议的图表与页码仍须教师核对。
- 增加浏览器听写入口：课件答疑、DSH 草稿、备课草稿、实验安排草稿、综合反馈。支持停止、权限或网络失败提示；生成文字后由人编辑、手动发送。真人麦克风与中文术语尚未验收。

## 后端协作待办

1. 正式入口 `https://learn1learn.stifer.xyz/learnbuddy/` 本次浏览器打开后跳到腾讯云“未完成备案”拦截页；当前不可作为已验证提交入口。IP 演示站与 API 可访问。
2. 补课程、作业、提交列表、提交创建及单份提交详情接口。当前在线作业目录和可选提交 ID 来自团队固定条目，状态不当作实时数据；学生不能正式提交或查询成绩。批量接口只有汇总，无法继续读取每份评分明细。
3. 提交门禁尚无接口：交错作业、缺任务点、退回补充以及教师侧异常状态仍需后端状态与持久化支持。前端未用自评分替代。
4. 知识点修改、答疑卡编辑确认、教学内容及作业创建发布接口尚未提供。在线端只展示服务端答疑卡、保留明确标注的临时草稿。
5. 按接口文档补齐密码与令牌校验、服务端角色及文件访问权限。当前 UI 筛选不是正式鉴权。
6. 恢复模型可用性，给所有评分响应补明确的模型、规则或降级来源；处理规则建议中与课程不匹配的图表引用。本轮在操作系统建议中观察到 Wireshark/RST 图表引用，应由后端核对来源。
7. 选择可用 HTTPS 演示入口后，实录验证语音输入。浏览器听写依赖浏览器支持与识别服务；当前代码在非安全来源提示使用 HTTPS 或本机预览，公网 HTTP 不能据此宣称语音可用。[浏览器接口参考](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/continuous)。
8. 在隔离数据库中完成真实文件上传解析、模型评阅、复核发布、学生读取反馈及异常提交回流的端到端验收，再同步公网版本。
